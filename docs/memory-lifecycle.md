# 长期记忆生命周期（赛道三·XH-202619）

知微把“记住什么”与“是否允许使用”分开管理。每条记忆包含来源、范围、敏感级别、重要性、证据摘录和版本链，用户可以在画像栏查看并执行确认、编辑或撤回。

## 生命周期

1. 对话反思器从当前用户消息提出 0–2 条候选认识，并必须绑定当前会话中的证据消息。
2. 系统校验证据归属、敏感信息和重复内容后写入活动版本。明确“记住/以后记得/请保存”时标记为 `explicit`；用户确认或编辑后标记为 `confirmed`；模型谨慎推断标记为 `inferred`。
3. `supersede` 和用户编辑会停用旧版本并生成新版本；撤回会停用活动版本并写入撤回记录。
4. 检索只读取当前用户、未过期、活动版本，并综合语义相关性、词面相关性、置信度、长期层级、重要性和确认新鲜度排序；敏感级别不会带来额外召回加分。
5. `memory_events` 记录 created、updated、confirmed、promoted、superseded、withdrawn、expired、used 等审计事件，便于复现和人工复核。

## 用户控制

- 画像栏显示记忆类别、长期/短期、来源标签。
- `盾牌`按钮确认模型推断；`铅笔`按钮直接编辑并生成确认版本；`撤回`按钮停用该认识。
- “长期记忆”开关关闭后停止写入和使用画像；“删除全部数据”仍走全量删除流程。

## 数据库与 localhost 演示

- 数据库模式使用 `packages/core/migrations/007_memory_lifecycle.sql`，需执行 `npm run db:migrate`。
- `NO_DB_MODE=true` 时使用进程内演示存储，支持同样的查看、确认、编辑、撤回闭环；重启 Node 进程后数据会清空，页面应将其视为演示状态，不等同于持久化部署。
