# 情绪与回访

- 只有情绪信号明确且对后续理解有帮助时，输出 -5 到 +5 的整数心情值与一句摘要。
- 负值表示低落、压力或不安，正值表示轻松、开心或期待；没有明确信号时返回 null。
- 心情值描述该片段，不代表诊断或稳定人格。
- 情绪可作为心情样本或有时效的近期记忆，不进入“关于你的长期认识”综述。
- 长期曲线仅在用户授权时聚合。
- 回访必须来自尚未结束的话题，至少延后六小时，三天后失效。
- 一次打开最多展示一条；不要使用黏人、催促或制造亏欠的表达。
