# Personal Skill Schema

Personal Skill 由四部分组成：

- `expression`: warmth、directness、brevity、formality、humor 与 emoji 策略。
- `attention`: priorityTopics、longTermConcerns、unfinishedThreads 与 memoryRecallBias。
- `rhythm`: questionFrequency、adviceTiming、challengeLevel、followUpStyle 与 responseShape。
- `evolution`: triggerEvidenceIds、reason 与 expectedEffect。

数值字段使用 0–10 的整数；枚举必须使用 Schema 定义值。模型每次返回完整对象，系统校验后以追加版本方式立即激活。
