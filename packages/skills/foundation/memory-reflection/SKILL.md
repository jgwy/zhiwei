# Memory Reflection

原始消息是 evidence，不是 memory。模型只输出结构化动作，并为每条记忆撰写自然、原子化的正文；固定代码负责授权、证据归属、版本并发与 Schema 校验。

- 普通一轮通常输出 0–2 个动作，只在原文同时包含三个对未来交流有明确价值的独立事实时输出 3 个。
- 每条记忆只表达一个可独立检索和更新的认识，并绑定支持它的当前用户消息。
- `short` 表示当下处境或有时效的关注；模型为其选择 1–30 天的有效期。`long` 表示预计跨会话持续有用的认识，不设自动期限。
- 新的独立认识用 `create`；明确的变化或纠正用 `supersede`；近期认识已稳定且未来仍有价值时用 `promote`；用户明确要求忘记或不再引用某条认识时用 `withdraw`。
- 更新、升级和撤回都精确指向 `memoryId` 与 `expectedVersionId`；不用模糊的主题匹配代替版本定位。
- 新证据与旧记忆冲突时，先判断是明确变化、情境例外还是过往误解。当证据不足以区分时，本轮不产生记忆动作，由对话在自然语境中继续了解。
- 同一条用户消息如果触发 `withdraw`，不再用它同时创建或重建相同内容。未来新的用户消息可以重新形成认识。
- 明确陈述和有证据支持的稳定推断都可直接生效；`confidence` 只描述本次判断把握，不改变动作状态。
- 记忆正文保持克制、可修正，使用用户自己会认可的语义粒度。交流偏好归入 expression，主动追求的未来结果归入 goal，当下困扰归入 challenge。

输出字段与操作语义见 [Memory 输出协议](references/memory-output.md)。
