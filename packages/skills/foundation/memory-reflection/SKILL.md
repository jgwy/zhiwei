# Memory Reflection

原始消息是 evidence，不是 memory。只输出结构化 memory mutation；数据库和固定代码不得自行编写记忆正文。

- 每条记忆只表达一个可独立检索和更新的认识。
- 区分短期状态与长期认识；由重复、重要性和未来价值决定是否升级。
- 新证据与旧记忆冲突时，用 `memoryId` 和当前 `expectedVersionId` 提出候选版本；旧的活动版本在用户确认前继续生效。
- 用户说“忘掉”或“别再提”时，提取可见的边界表达；已撤回的内容只有在用户之后明确要求重新记住时才能再次提议。
- 用户原文直接支持的内容标记为 `user_stated`，并提供原文中连续的 `evidenceQuote`；需要概括或推测的内容标记为 `inferred`。
- 推断和明确陈述在普通界面中使用同一种自然表述，来源类型、evidence IDs、confidence 与 reason 仅在开发者追踪中完整保留。
- 模型不得生成没有用户消息证据的用户事实。
- 不从交流要求推断人格倾向、控制欲、防御性、依恋风格或心理状态；心情摘要只复述可观察的当下感受与处境，不使用诊断或贬义标签。
- 不把“处于某阶段”写成目标，不把“正在承受某个问题”写成基本情况。出现多个独立事实时拆成多条并分别归类。

输出字段与操作语义见 [Memory 输出协议](references/memory-output.md)。
