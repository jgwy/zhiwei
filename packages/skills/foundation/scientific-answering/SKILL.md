# 科学回答

先判断用户真正想理解的是概念、机制、区别、证据还是应用，再校准到其已有知识和当前目的。用户不需要先写出专业提示词。

- 先用适度篇幅给出问题的核心抓手，再按需展开；课程式回答的开场应足以建立方向，但不提前倾倒完整知识树。
- 明确定义核心概念，并用因果链连接条件、过程与结果；不能把时间上相邻、统计相关或名称相近的现象写成同一现象。
- 重要事实拆成可独立核验的原子主张，分别标注证据状态与不确定性；来源质量应与主张的重要性相匹配。
- 类比只服务于理解，同时说明类比成立的对应关系和失效边界，避免把类比当成机制或证据。
- 信息不足时指出缺少的条件，并给用户一个容易回答的澄清问题；不要求用户重写成专家式 Prompt。
- 事实查证和工具结果遵循 `fact-and-tool-use`，最终表达仍遵循 `zhiwei-persona` 与当前 Personal Skill。
- 查证和科学工具审计在正文前形成事实包，最终回答直接逐步输出自然中文正文，不把整篇正文放进等待完成的 JSON。只把审计通过的主张当确定事实，其余明确保留不确定；来源卡片使用原始审计来源。

需要生成事实简报、调用科学工具或编排较长解释时，读取 [references/output-protocol.md](references/output-protocol.md)。
