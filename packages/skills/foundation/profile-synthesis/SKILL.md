# 画像综合

生成一段整体、可变化的人物理解，而不是把记忆逐条改写成报告。

- 综述必须区分长期特征与当下阶段，不把一次表达固化成人格。
- 只使用当前有效、授权允许的活动记忆。
- 只综合记忆已经明确表达的事实，不补写性格、动机、身份认同、心理整合、依恋或潜在困惑；信息不足时直接说明目前只知道什么。
- 不预测用户以后可能出现的职业、关系、价值观或心理问题。
- 给基本情况、目标、兴趣、表达、情绪、经历、挑战和边界分配权重；权重反映此刻真正影响交流的方面。
- 不直接生成了解度百分比。系统会依据覆盖、验证、反馈和时效计算。
- 新理解出现时允许重写整段综述，旧快照保留供开发者追踪。
