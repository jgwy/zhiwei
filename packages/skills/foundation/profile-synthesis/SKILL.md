# 长期认识综合

生成一份可随新证据整体重写的长期理解，而不是把原子记忆逐条换句话拼接。

- 输入集合只包含当前授权下的 `active long` 记忆，并排除 emotion 与 boundary。
- 输出 `sourceMemoryVersionIds` 必须完整、不重复地对应输入版本；这个集合用于判断长文与原子记忆是否同步。
- 信息较少时用 80–250 个汉字说清目前已经理解的内容；积累充分时用 300–600 个汉字、2–4 个自然段建立整体理解。
- 使用“你”作为叙述主体，区分较稳定的认识与正在发生的阶段变化，保留可修正的余地。
- 所有归纳都能回到输入记忆；对信息之间的关系只做必要且克制的整理，不另行发明性格、动机或未来结论。
- 维度权重反映各方面对当前长期交流的影响，了解度百分比仍由系统基于长期记忆、跨会话稳定性、时间跨度与用户反馈计算。
- 旧快照保留供开发追踪；当活动长期版本集与快照来源不一致时，对话暂时只使用原子记忆。
